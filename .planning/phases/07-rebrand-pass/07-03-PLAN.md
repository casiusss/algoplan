| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-03-01 | Tampering | electron-builder.yml appId change | accept | appId rename forces Windows installer to treat the app as a NEW install; macOS auto-updater handles via Sparkle/electron-updater feed; documented in SUMMARY for release-comm action |

| T-07-03-04 | Denial of Service | auto-updater on existing installs | mitigate | artifactName template kept (multica-desktop-${version}); existing electron-updater feeds keep working until next install completes — acceptable transitional cost |

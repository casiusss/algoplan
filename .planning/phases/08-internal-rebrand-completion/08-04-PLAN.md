```typescript
function initCore(...) {
  if (initialized) return;

      `localStorage migration: migrated=${report.migrated.length} skipped=${report.skipped.length}`,
    );
  }

  const api = new ApiClient(...);
  setApiInstance(api);
  ...
}
```

- Workspace-scoped key migration (`migrateWorkspaceScopedKeys`) is NOT called here because the workspace slug list is unknown at boot. It is called from `WorkspaceRouteLayout` (apps) AFTER auth resolves. For Phase 8, the simplest acceptable wire-up is: workspace-scoped keys migrate lazily when each workspace is first opened.
